# 📚 Projects

## 🧹 DNS Cache Cleaner

A Windows utility designed to perform common DNS and network maintenance
operations.

### Features

- DNS cache cleanup
- IP address release
- IP address renewal
- Winsock reset
- TCP/IP reset
- NetBIOS refresh
- Network maintenance operations

---

## 🛣️ Route Checker

A Windows network diagnostic utility designed to analyze network routes
using the standard Windows `TRACERT` command.

### Features

- IPv4 route tracing
- Destination IP or domain support
- Source country detection
- IP geolocation
- Country identification along the route
- Detection of possible international routes
- Identification of the first foreign country detected
- City and region information when available
- Organization and ASN information when available
- Private IP filtering
- Duplicate IP filtering
- Complete TRACERT output
- Portuguese and English interface

### Default Destination

If no destination is provided, the tool can use:

`200.160.2.3 - NIC.br`

### Requirements

- Windows
- Windows PowerShell 5.1 or newer
- Internet connection for IP geolocation
- Standard Windows `TRACERT`

## 🧹 Limpador de Cache DNS

Uma ferramenta para Windows desenvolvida para realizar operações comuns
de manutenção de DNS e rede.

### Funcionalidades

- Limpeza do cache DNS
- Liberação do endereço IP
- Renovação do endereço IP
- Redefinição do Winsock
- Redefinição do TCP/IP
- Atualização do NetBIOS
- Operações de manutenção de rede

---

## 🛣️ Verificador de Rota

Uma ferramenta de diagnóstico de rede para Windows desenvolvida para
analisar rotas utilizando o comando padrão `TRACERT`.

### Funcionalidades

- Rastreamento de rotas IPv4
- Suporte a endereço IP ou domínio de destino
- Detecção do país de origem
- Geolocalização dos endereços IP
- Identificação dos países encontrados na rota
- Detecção de possíveis rotas internacionais
- Identificação do primeiro país estrangeiro encontrado
- Informações de cidade e região quando disponíveis
- Informações de organização e ASN quando disponíveis
- Filtro de endereços IP privados
- Filtro de endereços IP duplicados
- Exibição completa do resultado do TRACERT
- Interface em Português e Inglês

### Destino padrão

Quando nenhum destino é informado, a ferramenta pode utilizar:

`200.160.2.3 - NIC.br`

### Requisitos

- Windows
- Windows PowerShell 5.1 ou superior
- Conexão com a Internet para geolocalização dos IPs
- `TRACERT` padrão do Windows
